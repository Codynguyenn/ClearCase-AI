## Secondary, fixed in advance (PROTOCOL.md section 7)

The "Topics this policy does not address" passage (`northwind-redaction-policy:1.0:10`) names topics on purpose, so it was the suspected easy match for not-addressed questions. It was served for 0 of the 95 questions in this set (2 of 44 in the first set); not-addressed questions shown **only** that passage: 0 of 13 wrongly shown here, 0 of 5 in the first set. So that confound did not drive the wrong shows; they come from other passages. It does not change the main numbers.

## Limits (PROTOCOL.md section 9)

Questions and labels come from language models, not people, and from the same family as the assistant under study. The writer was told what the two documents are about; the second labeler is the writer's own model, so it is a consistency check and not an independent expert. Keeping only questions both labelers agree on removes the ambiguous ones (46 of 145 candidates were unclear to at least one labeler), so the set is probably easier than real use. Two fictional policies and 19 passages. The same assistant wrote the policies, the prompts and this analysis. Not real users' questions.
